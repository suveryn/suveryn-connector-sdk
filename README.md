# suveryn-connector-sdk

A placeholder: nothing is built here yet. It will hold the contract, a template and a test harness for connectors to [suveryn-core](https://github.com/suveryn/suveryn-core), written by sūveryn or by third parties. The SDK comes after the notary playbooks and after the pack format and versioning rules are settled ([the order of work](https://github.com/suveryn/suveryn-core/blob/main/docs/design/platform.md#sequencing)).
